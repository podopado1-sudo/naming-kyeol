# 작명규칙 연구 및 적용 (2026-06-23)

전통 한국 작명규칙을 웹에서 조사·정리하고, 본 프로젝트 철학(**미학 우선, 미신 배제**)에
부합하는 것만 선별해 엔진에 반영한 기록.

## 불용한자 정책 — 채택 / 거부

작명규칙의 "불용한자"는 두 갈래이며, 본 프로젝트는 **명확히 구분**한다.

### ✅ 채택 — 불용한자(부정적 의미)
음(音)·훈(訓)의 뜻이 부적합한 글자. 좋은 이름의 합리적 기준이므로 배제한다.
- 죽음·재앙: 死亡喪屍厄禍凶 …
- 병·고통: 病疾痛苦患 …
- 악·범죄·형벌: 惡邪魔鬼罪犯刑獄賊盜殺 …
- 천함·열등·가난: 愚拙劣卑賤奴乞貧困 …
- 더러움·추함·부정감정: 醜汚臭怨恨怒哀 …
- 불쾌한 짐승: 犬狗豚鼠蛇蟲 …

구현: `HanjaData.ForbiddenNameHanjaSet` + `IsForbiddenNameHanja()`,
`NamePoolEngine`의 한자 풀에서 배제. (해당 발음에 좋은 대체 한자가 있으면 발음은 유지됨.)

### ❌ 거부 — 불길한자(미신)
뜻은 좋은데 "이름에 쓰면 흉하다"고 보는 류. **채택하지 않는다.** 근거(2026-06-23 검증):

- **전체 목록(~115자)이 한국 이름의 핵심 글자를 거의 다 포함.** 실제 목록 예:
  慶·光·貴·德·美·福·富·鳳·星·松·壽·淑·順·勝·愛·禮·銀·仁·眞·忠·海·孝·花·喜·香·輝·敏·雪 …
  → 美(아름다울)·淑(맑을)·愛(사랑)·禮(예의)·孝(효도)·香(향기)를 빼면 정상적인 이름을 못 만든다.
- **불길 사유가 순수 점술.** 命=재액, 女=천함, 風=재산 날림 류.
- **"같은 음 다른 한자로 대체" 논리도 여기선 안 통함** — 美가 곧 '미'의 대표 글자라
  대체재(米·眉)는 뜻이 더 나쁨. 불용(부정 의미)과 달리 불길은 *좋은* 대표 글자를 친다.
- **작명계 스스로 "사이비 불용문자"로 정리** (예: 한국작명교육협회 자료). 출처마다 목록이
  제각각이라 어차피 "완전한 미신 회피"는 불가능.
- 본 프로젝트 철학("사주로 이름을 만들지 않는다 / 미학 우선")과도 부합 → **거부 확정.**

> 참고: 사용자가 "미신에서 자유로운 이름"을 원할 수 있다는 논의가 있었으나, 위 목록을
> 적용하면 오히려 이름 품질을 망치고(美·淑·德 제거) 어차피 다른 목록엔 또 다른 글자가 있어
> 목표 달성 불가. 결론은 "불용(부정 의미)만 거르고 불길 미신은 무시"가 최선.

## 결론
1. 전통 작명규칙의 **합리적 부분은 이미 엔진에 구현**돼 있음(이번에 검증).
2. 빠져 있던 **불용한자(부정적 의미) 배제**를 추가 — 좋은 이름의 안전장치.
3. **불길한자 미신은 의도적으로 배제** — 이것이 본 서비스의 차별점이자 철학.
4. 작명규칙은 "맞는 이름(궁합·길흉)"을 다루지, "예쁜 이름(미감)"을 만들어주지 않음.
   창의·미감 품질은 별도 과제(큐레이션/데이터)로 다룬다.
