# 이름의 결 — Claude Design 브리프

> 이 문서를 **claude.com의 Claude Design**에 입력(첨부 또는 본문 붙여넣기)하여 UI 프로토타입을 생성하기 위한 통합 브리프입니다.
> 작성일 2026-04-21 기준. 백엔드 API는 실제 구현된 상태이며, 프론트는 Next.js 16.2로 구조는 있으나 디자인 시스템 미적용.

---

## 1. 한 줄 요약

**"이름의 결"** — 한국어 이름 추천·분석 웹 서비스. 미학(70%)과 사주 조화(30%)를 결합해 유행에 휩쓸리지 않는 단정한 이름을 제안합니다.

---

## 2. 서비스 개요

| 항목 | 내용 |
|------|------|
| 서비스명 | **이름의 결** |
| 한 줄 정의 | 이름을 짓는 중요한 순간을 돕는 플랫폼 |
| 타겟 범위 | 아기 이름 / 개명 / 예명 / 회사·상호명 / 반려동물 (점진 확장) |
| 기술 스택 | Next.js 16.2 (프론트) + ASP.NET Core 10 (백엔드) |
| 현재 상태 | 백엔드·API 완성, 프론트는 기능 구현됨, **디자인 시스템 미적용** |

### 차별점

- 사주/운명 위주의 기존 작명소와 달리 **미학(발음·리듬·음운) 우선**, 사주는 보조
- **"유행 이름 ❌, 소망형 이름 ❌, 세대 중립"** 추구
- 한자 오행·음양 판정에 **신뢰도 등급(S/A/B/C/D)** 표시
- 발음의 음운 특성을 **감점 없이 정보로** 노출 (예: "'ㅣ' 모음이 이어져 부드럽고 차분한 인상이에요")

## 3. 브랜딩 & 톤

### 카피 배치 맵

| 위치 | 문장 |
|------|------|
| 메인 히어로 H1 | "당신이라는 고유한 흐름이 아름다운 문장이 되도록." |
| 각 작명 페이지 상단 | "입술 끝에서 시작되어 마음속 깊이 남는 울림." |
| 브랜드 스토리/어바웃 | "좋은 소리는 결이 다릅니다. 부를수록 깊어지는 이름." |
| 상호/브랜드 작명 섹션 | "유행을 타지 않는 클래식, 이름의 결에서 발견하세요." |

### 스페어 카피

- "단순히 불리는 호칭이 아닌, 당신의 자부심이 될 이름의 무늬."
- "결이 고운 이름은 시간이 흐를수록 그 가치를 증명합니다."

### 말투 (UX 라이팅)

- 차분·단정. 점술스럽지 않고, 과학인 척도 않음.
- **좋은 예**: "의미와 발음의 균형을 함께 살펴봤어요"
- **나쁜 예**: "당신의 운명을 바꿀 최고의 이름"

## 4. 디자인 방향 — "부드러운 전문성"

비율: **전문성 70% + 친절함 20% + 감성 10%**

| 요소 | 방향 |
|------|------|
| 첫인상 | 진중 — 안심감 |
| 사용감 | 쉽고 부드러움 |
| 결과화면 | 감성적 만족 |
| 확장성 | 매우 높게 (아기이름 외 확장 대비) |

### 컬러 팔레트 (제안)

| 역할 | 색 | 비고 |
|------|------|------|
| 배경 | 따뜻한 화이트 / 아이보리 | 풀 다크 금지 (너무 무거워짐) |
| 본문 글자 | 진한 차콜 | #2B2B2B 계열 |
| 포인트 1 | **딥 네이비** 또는 **청록** | 버튼/강조/뱃지 |
| 포인트 2 | 부드러운 금베이지 | **소량만** — 고급감 포인트 |
| 보조 | 옅은 종이질감, 나뭇결/물결 라인 | 배경 텍스처 10~15% opacity |

### 타이포그래피

- 한글 제목: 무거운 명조/세리프보다 **모던 세리프** 또는 clean sans (예: Pretendard, Spoqa Han Sans Neo)
- 본문: 가독성 좋은 sans
- 한자: 명조 계열 (고급스러움), 크기 약간 크게

### 전통 요소 사용 원칙

- **포인트만** — 인장, 여백, 종이질감 미세하게
- **피하기**: 붓글씨 남발, 한문 배경 과다, 금룡/봉황/팔괘, 핑크/파스텔, 과한 일러스트

### 홈 분기 (미구현, 추가 필요)

홈 진입 시 **"어떤 이름을 찾고 있나요?"** 분기:

- 🍼 **아기 이름** — 축복의 분위기
- ✍️ **개명** — 전환·재시작
- 🏢 **회사명/상호** — 전략·신뢰
- 🐶 **반려동물** — 친근·발랄

각 분기는 감정이 다르므로 **카드 비주얼·문구·다음 단계**가 달라야 합니다.

## 6. 핵심 화면 5개 명세

### 화면 1 — 홈 (메인 진입)

**목적**: 서비스 가치 전달 + 타겟 분기 유도

**레이아웃**:
- 히어로 — 카피 H1 "당신이라는 고유한 흐름이 아름다운 문장이 되도록." + 부드러운 fade 로테이팅 서브라인
- 배경: 따뜻한 아이보리 + 옅은 물결/나뭇결 라인
- **분기 카드 4개** (아기이름/개명/회사/반려) — 각각 아이콘 + 짧은 설명 + "시작" CTA
- 하단 — 서비스 원칙 3가지(유행 X, 세대 중립, 발음 우선) 간결한 섹션
- 풋터 — 브랜드 스토리 링크, 블로그(옵션)

### 화면 2 — 스마트 추천 결과 (가장 중요)

**목적**: 여러 엔진 결과를 탭으로 묶어 보여주면서 **"추천 1위"를 상단 강조**

**실제 API 응답 구조 (이번 세션에서 확정)**:

```typescript
interface SmartRecommendationResponse {
  lastName: string;
  isRareSurname: boolean;
  rarityLevel: number;          // 0~3
  totalCount: number;
  topPick: {                    // ★ 추천 1위 (신규)
    categoryType: string;       // 예: "standard"
    categoryLabel: string;      // 예: "한자 이름"
    candidate: SmartNameCandidate;
  } | null;
  categories: NameCategory[];   // 순서 고정됨 (아래)
}

interface NameCategory {
  type: string;                 // "standard" | "pure-korean" | ...
  label: string;                // 한글 표시명
  engineUsed: string;
  names: SmartNameCandidate[];
}

interface SmartNameCandidate {
  name: string;                 // 예: "민준"
  fullName: string;             // 예: "김민준"
  meaning: string;
  score: number | null;
  tags: string[];
  phonologyNotes: PhonologyNote[]; // ★ 음운 특성 (신규)
}

interface PhonologyNote {
  id: string;                   // 예: "r_initial_after_final"
  name: string;                 // 예: "받침 뒤 ㄹ 초성"
  message: string;              // 사용자 노출 메시지
  position: number;             // 0-based 음절 위치
}
```

**카테고리 탭 순서 (백엔드에서 고정됨)**:
1. `standard` 한자 이름 ← **항상 첫 번째**
2. `pure-korean` 순우리말
3. `three-syllable` 3글자 이름
4. `creative` 창의적 작명
5. `parent-based` 부모 기반
6. `required-char` 필수 글자
7. `dual-name` 영어+한자
8. `twin` 쌍둥이
9. `rare-surname` 특이 성씨

**레이아웃**:

```
┌─────────────────────────────────────────────┐
│  [🌟 추천 1순위]                              │
│  ┌─────────────────────────────────────┐    │
│  │ 김민준      한자 이름 · 92점          │    │
│  │ 民俊 — 백성 민, 준수할 준              │    │
│  │ [상세 평가 →]                         │    │
│  └─────────────────────────────────────┘    │
├─────────────────────────────────────────────┤
│  [한자 ▾] [순우리말] [3글자] [창의] ...      │ ← 탭 (가로 스크롤)
├─────────────────────────────────────────────┤
│  NameCard 리스트 (그리드 또는 세로)          │
│   ┌────────────┐ ┌────────────┐              │
│   │ 김민준     │ │ 김서준      │              │
│   │ 92점       │ │ 89점        │              │
│   │ 民俊       │ │ 敘俊        │              │
│   │ 백성, 준수 │ │ 서술, 준수  │              │
│   │ 🏅고신뢰   │ │            │              │
│   │ [상세평가]│ │ [상세평가]  │              │
│   └────────────┘ └────────────┘              │
├─────────────────────────────────────────────┤
│  [조건 바꿔서 다시 추천받기]                 │
└─────────────────────────────────────────────┘
```

### 화면 3 — NameCard (컴포넌트 핵심)

**포함 요소**:
- 성+이름 (볼드, 큰 글씨)
- 점수 (색상 구분: 90+ 초록, 80+ 청록/블루, 70+ 노랑)
- 한자 + 뜻 (있는 경우)
- 한자 신뢰도 뱃지:
  - **S등급** → `🏅 고신뢰` (골드/청록)
  - **D등급** → 하단 또는 `⚠ 전문가 확인 권장` 미묘하게
  - A/B/C → 뱃지 없음
- 태그 (카테고리, 3글자 등)
- **PhonologyNote 인라인 표시** — 작은 회색 텍스트로 "'ㅣ' 모음이 이어져 부드럽고 차분한 인상이에요" 같은 메시지 (감점 아님, 정보 노출)
- [상세 평가 →] 버튼

### 화면 4 — 분석 페이지 (/analysis)

**목적**: 이름을 입력받아 사주 원국 + 발음·의미 분석 결과 출력

**핵심 블록**:
1. 입력 폼 — 성/이름/생년월일/시간/출생지 (17개 시/도 진태양시 보정)
2. 사주 원국 카드 — 년주/월주/일주/시주 4기둥 시각화 (천간·지지 한자 + 한글)
3. 오행 분포 막대 — 木/火/土/金/水 비율
4. 이름 발음 분석 — PhonologyNote 상세
5. 종합 평가 — 조화/균형 한두 문장

### 화면 5 — 상세 평가 페이지 (/evaluate)

**목적**: 개별 이름의 점수 구성 + AI 종합 해석

**핵심 블록**:
1. 이름 헤드 — 성명 큼직하게 + 한자 병기
2. 점수 브레이크다운 카드 — 미학(발음·리듬·음절·세대중립·의미) + 조화(오행·자원오행·음양·성조화)
3. 한자 후보 카드 — 동일 발음의 다른 한자 옵션 + 신뢰도 뱃지 + 툴팁(오행 판정 근거)
4. AI 해석 카드 — Claude Haiku가 생성한 3줄 설명 (배경색 살짝 다르게, 감성 포인트)
5. 주의사항 — 선택적

> 추가로 마스코트 4종(여우/달토끼/붓요정/학) 일러스트 스케치도 같이 제안해줘. 모바일·데스크탑 각각 반영."

## 10. 결과물 체크리스트 (Claude Design 출력 받은 후)

- [ ] 히어로 카피가 명시된 문장 그대로 들어가 있는가
