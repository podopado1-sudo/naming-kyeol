# 이름의 결 — 디자인 시스템 설정 (Claude Design 입력용)

> **사용법**: Claude Design의 "Set up design system" 클릭 → 아래 내용 그대로 붙여넣기

---

## 브랜드

- **이름**: 이름의 결 (Naming.kyeol)
- **장르**: 한국어 이름 추천·분석 웹 서비스
- **타겟**: 아기 이름·개명·회사명·반려동물 작명 수요자
- **핵심 가치**: 유행 ❌, 세대 중립, 발음과 의미의 균형
- **컨셉**: 부드러운 전문성 (전문성 70% + 친절함 20% + 감성 10%)

## 컬러 팔레트

### Primary
- `background`: `#FAF7F2` (따뜻한 아이보리) — 메인 배경
- `surface`: `#FFFFFF` — 카드/패널
- `text-primary`: `#2B2B2B` (진한 차콜) — 본문
- `text-secondary`: `#6B6B6B` — 보조 텍스트

### Accent
- `primary-accent`: `#1E3A5F` (딥 네이비) — 버튼·중요 강조
- `secondary-accent`: `#2E7D7A` (청록) — 태그·링크·포인트
- `gold-beige`: `#C9A96E` (부드러운 금베이지) — **소량만**, 고급감 포인트 (뱃지·구분선)

### Semantic (점수용)
- `score-high`: `#4A7C59` (차분한 녹색) — 90+ 점
- `score-mid`: `#5B7FAA` (부드러운 블루) — 80+ 점
- `score-low`: `#B5874C` (머스타드) — 70+ 점

### 금지색
- 붉은색 계열 금룡, 금박 과다
- 형광 핑크·파스텔 과다
- 순수 블랙 배경 (너무 무거워짐)

## 타이포그래피

### 한글
- **Display/Heading**: Pretendard Variable 또는 Spoqa Han Sans Neo (모던 sans, 무게 600~800)
- **Body**: Pretendard 400~500
- **Serif 포인트**: Nanum Myeongjo — 한자·카피 강조 시에만

### 한자
- Nanum Myeongjo 또는 Noto Serif KR — 본문보다 **살짝 큰 크기**

### 영문
- Inter / Geist — 숫자·영문 혼용 시

### 스케일
- H1: 40px / 1.2 / 700
- H2: 28px / 1.3 / 700
- H3: 20px / 1.4 / 600
- Body: 16px / 1.6 / 400
- Caption: 13px / 1.5 / 400

## 간격 (Spacing)

8px 기반 그리드: `4, 8, 12, 16, 24, 32, 48, 64`

## 둥근 모서리 (Radius)

- `sm`: 6px — 뱃지
- `md`: 12px — 버튼·인풋
- `lg`: 20px — 카드
- `xl`: 32px — 히어로·섹션

## 그림자 (Shadow)

부드럽게, 진하지 않게:
- `sm`: `0 1px 2px rgba(0,0,0,0.04)`
- `md`: `0 4px 12px rgba(0,0,0,0.06)`
- `lg`: `0 8px 24px rgba(0,0,0,0.08)`

## 텍스처·패턴

**옅게**(5~10% opacity)만 사용:
- 종이 질감 (아이보리 배경에 은은하게)
- 물결 / 나뭇결 곡선 (브랜드 "결"의 은유)
- 인장 모티프 (배지·포인트에 작게)

**피할 것**: 붓글씨 배경, 한문 대형 무늬, 팔괘·태극·금룡·봉황

## 핵심 컴포넌트

### Button
- **Primary**: 딥네이비 배경 + 아이보리 글자 + radius md
- **Secondary**: 청록 아웃라인 + 청록 글자
- **Ghost**: 밑줄만, 차콜 글자

### Card (NameCard)
- surface 배경 + radius lg + shadow sm
- 상단: 성명(H2) + 점수(우측 정렬, 색상 구분)
- 중단: 한자 + 뜻
- 하단: 태그(청록 배경 칩) + 상세 평가 링크

### Badge
- **고신뢰 뱃지** (S등급): gold-beige 배경 + 차콜 글자 + radius sm + 작은 🏅 아이콘
- **경고 뱃지** (D등급): 회색 테두리 + 회색 글자 + "전문가 확인 권장"

### Input
- surface 배경 + 1px 차콜 20% 테두리 + radius md
- focus: 청록 2px 테두리
- placeholder: text-secondary

### Tab
- 밑줄 스타일 (배경 칠 ❌)
- active: 딥네이비 밑줄 2px + 딥네이비 글자
- inactive: text-secondary

### Tooltip (한자 rationale용)
- 차콜 85% 배경 + 아이보리 글자 + radius md
- 최대폭 320px, 본문 14px

## 목소리(Voice) 샘플

- ✅ "의미와 발음의 균형을 함께 살펴봤어요"
- ✅ "입술 끝에서 시작되어 마음속 깊이 남는 울림"
- ✅ "결이 고운 이름은 시간이 흐를수록 그 가치를 증명합니다"
- ❌ "당신의 운명을 바꿀 최고의 이름"
- ❌ "100% 대박, 2026 최고 이름 랭킹"

## 마스코트 (옵션)

4종 후보 — 선화 스타일 + 포인트 컬러(청록 or 금베이지) 1~2색으로 심플하게:

- 🦊 여우 — 영리함·신비
- 🌙 달토끼 — 한국 전래·부드러움
- 🖌️ 붓 요정 — 서예·작명 직결
- 🦢 학/두루미 — 고급·장수

→ 4종 시안을 병렬 제안해주세요.
