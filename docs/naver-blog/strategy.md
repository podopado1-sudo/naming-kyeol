# 네이버 블로그 연계 전략 (2026-07 킥오프)

> SEO 2순위 전략(콘텐츠→**네이버**→제2도메인). 구글 색인이 8월 초까지 관찰 대기인 공백을
> 네이버 유입으로 메운다. 한국 검색에서 일반 웹사이트는 네이버 노출이 구조적으로 불리하므로,
> 네이버 안의 자산(블로그)을 만들어 사이트로 퍼널을 잇는다.

## 확정 사항 (2026-07-22 사용자 결정)

| 항목 | 결정 |
|------|------|
| 계정 | 기존 네이버 계정 사용, 블로그는 새로 개설 (계정 연식 일부 인정) |
| 페르소나 | **만드는 사람 개인 톤** — "작명 서비스를 만드는 사람의 이름 이야기" |
| 발행 리듬 | **주 2회** (초안은 Claude, 발행 전 직접 다듬기 필수) |
| 콘텐츠 기둥 | **이름 데이터 시리즈 단일 기둥** (C-Rank 주제 일관성) |

## 네이버 노출 로직 요약 (2026 기준)

- **C-Rank** (블로그 단위 신뢰도): "특정 주제를 꾸준히" — 단일 기둥·주 2회가 정확히 이 신호.
- **D.I.A** (문서 단위 품질): 2026 하이퍼클로바X 기반 문서 분석 강화. 원본 이미지 가산,
  키워드 나열 감점, 맥락·정보 정확성 평가.
- **스마트블록**: 라이프스타일 키워드의 80%+가 주제 묶음으로 노출. 체류시간 평균
  **2분 30초~3분 이상**이 상위권 유지 조건 → 글 분량 1,200자+ / 표·이미지로 읽는 시간 설계.
- **신규 블로그 냉대**: 최적화까지 수개월. 초반 3개월은 롱테일 키워드만 노리고
  순위 기대치를 낮게 잡는다 (성과 지표: 노출보다 발행 리듬 유지).

## 저품질 회피 수칙 (발행 전 체크리스트)

1. **외부링크는 글당 최대 1개** (namingkyeol.com — 본문 말미, 자연스러운 문맥으로)
2. **AI 초안 그대로 복붙 금지** — 발행 전 반드시:
   - 말투를 자기 말투로 다듬기 (최소 30% 문장 수정 감각)
   - 개인 경험/의견 한 단락 직접 추가 (초안에 `[여기에 직접]` 표시해 둠)
   - 문단 순서 1곳 이상 재배치
3. **키워드는 글당 4~5회만** (제목 1 + 본문 3~4 — 초안에 카운트 표시)
4. **원본 이미지 2장 이상** — 직접 캡처/제작 (사이트 화면 캡처, 데이터 표 스크린샷,
   손으로 만든 차트). 스톡 이미지 금지.
5. 같은 글 내 동일 문장 반복 금지, 타 블로그/사이트 문장 복사 금지 (자기 사이트 포함 —
   /name·/guide 문장 재사용 시 반드시 재서술)

## 블로그 세팅 가이드 (개설 시)

- **블로그명 후보**: ① 이름 짓는 사람 ② 결 고운 이름 연구소 ③ 이름 데이터 노트
  (검색 시 식별되는 고유명 + 주제가 드러나는 조합 권장 — ① 추천)
- **카테고리**: `이름 데이터` / `이름 뜻` / `작명 일기` 3개 이하로 시작 (주제 일관성)
- **프로필 소개**: "이름 추천 서비스를 만들며 대법원 출생신고 데이터 수백만 건을
  들여다보는 사람. 데이터로 보는 이름 이야기를 씁니다." 톤 유지, 링크는 프로필에만 1개.
- **이웃 활동**: 임신·육아·작명 주제 블로그 위주로 소량이라도 진성 활동 (체류·이웃 신호)

## 키워드 맵 (신규 블로그 = 롱테일부터)

| 티어 | 키워드 | 비고 |
|------|--------|------|
| T1 (초반 3개월) | 중성적인 아기 이름, 받침 없는 아기 이름, 흔하지 않은 아기 이름, 남녀공용 이름, 아기 이름 뜻 | 경쟁 낮음·데이터 강점 직결 |
| T2 (최적화 진행 후) | 신생아 이름 순위, 여자 아기 이름 추천, 남자 아기 이름 추천, 순우리말 이름 | 스마트블록 경쟁 중 |
| T3 (장기) | 아기 이름 추천, 작명, 이름 짓기 | 최상위 경쟁 — 블로그 성숙 후 |

## 4주 발행 캘린더 (8편)

| 주차 | 편 | 주제 (타깃 키워드) |
|------|----|--------------------|
| 1주 | 1 | 남녀 이름 TOP 10, 데이터로 보면 이렇게 다릅니다 (신생아 이름 순위) — ✅ 초안 완료 |
| 1주 | 2 | 아들 이름인 줄 알았는데 — 데이터가 말해주는 중성 이름 (중성적인 아기 이름) — ✅ 초안 완료 |
| 2주 | 3 | 이름 끝 글자만 봐도 성별이 보인다? 끝음절 데이터 분석 (아기 이름 짓기) |
| 2주 | 4 | 흔하지 않은데 예쁜 이름은 진짜 있을까 — 희귀 실명 데이터 (흔하지 않은 아기 이름) |
| 3주 | 5 | 유주는 98%가 여자아이 — 이름과 성별의 통계학 (남녀공용 이름) |
| 3주 | 6 | '서'로 시작하는 이름이 유독 많은 이유 (아기 이름 뜻) |
| 4주 | 7 | 받침 없는 이름이 부드럽게 들리는 이유 — 발음 데이터 (받침 없는 아기 이름) |
| 4주 | 8 | 쌍둥이 이름은 어떻게 맞출까 — 공유 글자 데이터 (쌍둥이 아기 이름) |

## 퍼널 설계

- 글당 링크 1개: 글 주제와 맞는 사이트 페이지로만 (`/name/[이름]`, `/search`, `/guide` 등)
- 링크 문구는 광고 아닌 도구 소개 톤: "직접 만들어 쓰는 도구인데, ○○ 이름의 통계는
  여기서 볼 수 있게 해뒀다" 식
- UTM: `?utm_source=naver_blog&utm_medium=post&utm_campaign=data01` 형태로 편번호 부여
  (리퍼러 유실 대비 — 유입 검증용)

## 운영 파이프라인

1. Claude가 `docs/naver-blog/posts/`에 초안 작성 (데이터는 name-seo.json 실측)
2. 사용자가 저품질 회피 수칙 2번대로 다듬어 발행 (회당 20~30분)
3. 발행 후 URL을 세션에서 알려주면 다음 초안에 내부 맥락(이전 글 링크 등) 반영
4. 4주 후 1차 리뷰: 블로그 통계(조회·유입 키워드·체류시간) + 사이트 리퍼러 확인 →
   키워드 티어 조정
