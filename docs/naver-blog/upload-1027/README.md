## 1. 한결 (권장)

링크한 /name/한결 이 네 조합 카드를 그대로 보여 줘서 글과 바로 어긋난다. 지금 페이지: **韓決·韓潔·漢結·翰結**
(발행 때 漢決·漢結·翰結·韓結 — 韓結 은 10/22, 漢決 은 10/27 배포에서 빠졌다).

1. 문장 4곳을 바꾼다 (편집기에서 앞부분으로 찾는다)
   - '한자 네 조합은…' 섹션, 표 아래 첫 문단:
     `결단할 결(決)과 맺을 결(結)은 매듭이나 결정을 뜻하지, 변함없음을 뜻하지 않습니다.`
     → `결단할 결(決)·맺을 결(結)·깨끗할 결(潔)은 결정과 매듭, 깨끗함을 뜻하지, 변함없음을 뜻하지 않습니다.`
   - 같은 섹션 둘째 문단 전체:
     `넷 중에서는 뒤 글자가 갈림길입니다. 決는 한 번의 결단을, 結은 이어 맺는 인연을 그려요. 셋이 結이고 하나만 決이니, 한자로 쓰는 한결은 대체로 '맺는 쪽'에 서 있습니다.`
     → `넷 중에서는 뒤 글자가 갈림길입니다. 決는 한 번의 결단을, 結은 이어 맺는 인연을, 潔은 맑은 깨끗함을 그려요. 結이 둘, 決과 潔이 하나씩이니, 한자로 쓰는 한결은 '맺는 쪽'이 조금 더 많은 정도입니다.`
   - 정리 첫 줄 (발행본은 `翰結·` 뒤에 띄어쓰기가 있다): `한자 네 조합(漢決·漢結·翰結· 韓結)은` → `한자 네 조합(韓決·韓潔·漢結·翰結)은`
   - 정리 둘째 줄 끝: `네 조합 중 셋은 맺을 결(結) 쪽입니다` → `네 조합 중 둘은 맺을 결(結) 쪽입니다`
2. 첫 번째 사진(표)을 지우고 그 자리에 `1-한결-표-새것.png`. 두 번째 사진(페이지 캡처)은 그대로 둔다(바뀐 값 없음).
3. 맨 끝 문단('…댓글로 남겨 주세요.') 아래에 붙인다(날짜는 고치는 날로):
   > 수정(2026.10.27): 처음 올릴 때 제 도구의 한결 페이지 조합은 漢決·漢結·翰結·韓結이었는데, 조합을 다시 고르면서 지금은 韓決·韓潔·漢結·翰結입니다. 그래서 조합 이야기와 표를 지금 페이지에 맞춰 고쳤어요. 대표 뜻과 출생신고 수치는 그대로입니다.
4. 발행 → ✓ 발행 → 대표 이미지 확인.

- 그대로 두는 것: 대표 뜻 "맑고 깨끗하게 한결같은"(순우리말 이름 뜻 — 韓潔 과 낱말이 겹쳐 보여도 '우리말 쪽에서 가져와' 문장은 맞다), 통계, 2편 링크, 키워드 4회.
- 기록: `../posts/18-한결-이름-뜻.md` 끝 '2026-10-27 배포 뒤 확인'.

## 2. 하엘 (10/23 수정안을 붙일 때)

10/23 수정안은 아직 발행본에 없다 — 발행본이 여전히 "하늘처럼 넓고 포근한"을 인용하는데 링크한 /name/하엘 에는 이 뜻이 없다. 보류 기록은 없다.
붙이기로 하면 아래대로 한다. 바뀐 것은 캡처뿐이다: 10/23 캡처(81점)는 10/26 배포 뒤 낡아(지금 78점 · 성별 보너스 줄 없음) 같은 틀로 다시 찍었다.

1. 문장 3곳 (발행본 문장 그대로):
   - `'엘'로 읽는 인명용 한자는 0자입니다` 섹션 끝:
     `제가 만드는 이름 도구는 하엘의 대표 뜻을 "하늘처럼 넓고 포근한"으로, 서사를 "하늘처럼 트여 있어 누구든 부드럽게 품어 안는 마음"이라고 적는데, 이건 한자 풀이가 아니라 소리의 풀이입니다.`
     → `제가 만드는 이름 도구도 하엘에는 대표 뜻을 따로 적지 않습니다. 하엘처럼 '-엘'을 붙여 새로 지은 이름은 기댈 원어 이름이 없어서, 뜻을 하나로 정할 근거가 분명하지 않거든요. 하엘에 담긴 건 한자 풀이가 아니라 소리입니다.`
   - 정리 첫 줄 앞부분:
     `하엘 이름 뜻의 대표 풀이는 "하늘처럼 넓고 포근한" — 한자 풀이가 아니라 소리의 풀이입니다.`
     → `하엘 이름 뜻은 한자 풀이가 아니라 소리에 있습니다 — 근거가 분명한 대표 풀이가 없어 제 도구에도 따로 적지 않습니다.`
   - 말미 링크 앞: `하엘의 통계와 풀이를 한 번에 보고 싶다면,` → `하엘의 출생신고 통계와 발음·미학 점수를 한 번에 보고 싶다면,`
2. 말미 링크 문장 아래에 `2-하엘-캡처-새것.png` 를 **새로 넣는다**(발행본 사진은 표 1장뿐이다).
3. (선택) 표 사진을 다엘·조엘을 더한 10행 표 `../images/mean03-hael-table-v2.png` 로 바꾸면 본문 '10개만 추려 보면'·'위쪽 다섯'과 맞는다(10/23 수정안의 (가)).
4. 맨 끝에 붙인다(날짜는 붙이는 날로):
   > 수정(2026.10.23): 처음 올릴 때는 제 도구의 하엘 페이지에 대표 뜻("하늘처럼 넓고 포근한")과 서사가 적혀 있어 본문에 그대로 옮겼습니다. 지금은 하엘처럼 '-엘'을 붙여 새로 지은 이름은 원어 이름이 없어 뜻을 하나로 정할 근거가 분명하지 않아 뜻풀이를 싣지 않기로 해서, 그 인용을 빼고 본문과 페이지 캡처를 고쳤어요. 하엘이 한글로만 등록하는 이름이라는 내용과 출생신고 통계, '-엘' 갈래 표는 그대로입니다.

   3번으로 표를 바꿨다면 마지막 문장만: `하엘이 한글로만 등록하는 이름이라는 내용과 출생신고 통계는 그대로이고, '-엘' 갈래 표에는 본문에서 함께 다룬 다엘·조엘을 더했습니다.`
   캡처를 '고쳤다'가 아니라 새로 넣는 것이라, 원하면 '본문과 페이지 캡처를 고쳤어요' → '본문을 고치고 페이지 캡처를 더했어요'.
5. 발행 → ✓ 발행.

## 3~6. 정·우·온·아 표 사진 (선택)

표 '이런 이름에' 칸의 예시 몇 개가 이름 페이지 조합에서 빠졌다. 글이 링크한 /hanja 페이지는 이름 조합을 보이지 않아 독자가 알아채기 어렵다 — 그래서 선택.
바꾼다면 **첫 번째 사진(표)만** 지우고 같은 자리에 새 사진을 넣는다. 본문·캡처·수정 안내는 그대로.

| 글 | 바뀐 예시 (옛 → 새) | 그대로인 것 |
|---|---|---|
| 정 | 靜 민정 敏靜→民靜 · 情 정우 情佑→情宇 · 精 정훈 精薰→민정 民精 · 貞 정훈 貞訓→정인 貞璘 | 나머지 예시 8개 · 오행 · 제목 |
| 우 | 瑀 찬우(燦瑀)·우찬(瑀燦) → 우림(瑀林) | 108·108·5·4 (9월 실측) |
| 온 | 昷 나온(羅昷) → '지금은 이름 조합에 없음' | 28·26·2·2·1 (9월 실측) |
| 아 | 亞 아린·세아·슬아 → 연아·아라·아림 | 175·158·50·5 (9월 실측) |

- 정 편 수정 안내에 밝히고 싶으면 끝에 한 문장: `표 예시는 10월 27일에 이름 페이지 조합에 맞춰 한 번 더 바꿨습니다.`
- 기록: 각 초안(`../posts/04`·`10`·`11`·`17`) 끝 '2026-10-27 배포 뒤 확인'.
