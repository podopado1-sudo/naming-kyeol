# 10/24 블로그 마무리 — 정·우·온·유 (통째로 붙여 넣기)

글마다 같은 순서로 한다. 본문 html 은 지금 발행본을 바탕으로 고칠 문장·글 끝 수정 안내를 반영한 완성본이다(유 편 겹친 첫 문단도 지움).

1. `<번호>-<글>-본문.html` 을 크롬으로 연다 → **Ctrl+A, Ctrl+C**
2. 네이버 블로그에서 그 글 '수정' → 본문 클릭 → **Ctrl+A, Delete** → **Ctrl+V** (제목은 그대로 둔다)
3. 노란 줄 `【사진 넣기: …】` 두 개를 지우고 그 자리에 같은 이름 사진을 넣는다 — `-표-새것.png`, `-캡처-새것.png`
4. 오른쪽 위 **발행** → 설정 창 맨 아래 **✓ 발행**까지 누른다
5. (유 편) 대표 이미지가 새 표로 되어 있는지 본다

- 순서: 정 → 우 → 온 → 유 (우 편이 고친 정 편 값을 되짚는다).
- 붙여 넣은 뒤 글자 색·크기가 달라 보이면 편집기에서 맞춘다(발행본은 회색 #555, 본문 13·소제목 19).
- 유 편 본문에는 137자(첫 문단·0회 절)와 136자(정리 첫 줄·사전 링크 문단)가 섞여 있다 — 발행본 그대로 둔 것. 맞추려면 정리 첫 줄의 136을 137로(표도 137).
- 같은 내용의 마크다운은 각 초안 md 의 '## 발행용 본문 (2026-10-23 수정 반영 — 이것을 붙여 넣을 것)' 절. 옛 '본문 초안'은 붙여 넣지 말 것.
- 정정 글(27)을 올린 뒤에는 각 글 끝 수정 안내 끝에 그 링크만 더한다.
